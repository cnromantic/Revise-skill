# 输出验收清单

处理完成后，用本清单检查输出是否符合 Revise v3.2 要求。

## 一、通用检查

| 检查项 | 要求 |
|---|---|
| 源文件保护 | 源 Word/PDF 未被覆盖 |
| 修改稿 | 已生成对应格式的修改稿 |
| 修改说明 MD | 已生成 `论文题目-修改说明.md` |
| 修改说明 PDF | 已生成 `论文题目-修改说明.pdf`，表格线清晰、字号可读 |
| 人工确认 | 无法核验或无法直接修改的问题已列入人工确认 |
| 编造风险 | 未编造实验、测试、截图、系统功能、参考文献 DOI/URL/卷期/页码 |
| 中英文混排 | 正文中汉字与英文术语、英文缩写之间的必要半角空格未被误删；英文紧邻中文标点时，英文与中文标点之间未误加空格 |

## 二、Word 验收

| 检查项 | 要求 |
|---|---|
| 复制流程 | 先复制源 Word 为修改稿，再在副本上局部修改 |
| 版式保留 | 图片、表格、脚注、页眉页脚、引用上标未明显丢失 |
| 黄色高亮 | 修改处或问题处已黄色高亮，未整段无差别变黄 |
| 自动编号 | 参考文献和标题自动编号未被重复添加 |
| 复杂格式 | 无法可靠处理的上标、域代码、超链接等已列入说明 |

## 三、PDF 验收

| 检查项 | 要求 |
|---|---|
| 复制流程 | 先复制源 PDF 为修改稿 PDF，再添加批注 |
| 批注位置 | 批注靠近问题位置，未遮挡需要修改的问题文字 |
| 正文替换声明 | 未真正替换正文时，只称为“批注式修改稿” |
| 页面级批注 | 无法定位、扫描件或无文本层限制已在说明中写明 |

## 四、同篇 Word/PDF 验收

| 检查项 | 要求 |
|---|---|
| 同主名文件 | 同主名 Word 和 PDF 同时存在时，默认只处理 Word |
| 跳过记录 | 跳过 PDF 的原因已写入修改说明、汇总或处理日志 |
| 不确定同篇 | 无法判断是否同篇时，没有自动跳过，已列入人工确认 |

## 五、参考文献验收

| 检查项 | 要求 |
|---|---|
| 引用顺序 | 已检查正文首次引用顺序与参考文献列表顺序 |
| 真实性核验 | 已尽力核验 DOI、Crossref、官网或数据库可访问页面 |
| 引用正确性 | 已判断正文引用语境与文献主题是否基本匹配 |
| 未核验项 | 环境不可联网或数据库不可访问时，未核验项已如实列出 |
| 禁止编造 | 未补造 DOI、URL、卷期、页码或出版信息 |
| DOI 写入边界 | 未因核验到 DOI 就强行加入论文参考文献列表 |

## 六、批量处理验收

| 检查项 | 要求 |
|---|---|
| 逐篇输出 | 每篇实际处理论文均生成对应修改稿和修改说明 |
| 汇总文件 | 已生成 `X篇论文处理汇总.md` 和 `X篇论文处理汇总.pdf` |
| 计数准确 | 实际处理数、跳过 PDF 数、输出完整性统计准确 |
| 人工复核 | 批量汇总包含人工复核清单 |
