# 参考文献真实性核验与引用正确性判断规则

## 一、总原则

默认开展参考文献真实性核验和引用正确性判断，但不得编造核验结果。核验结果用于修改说明、人工复核和风险提示，不强制写入论文参考文献列表。

## 二、核验范围

1. 正文引用序号是否连续，是否存在未列入参考文献表的引用。
2. 参考文献列表是否存在未被正文引用的条目。
3. 参考文献列表顺序是否与正文首次引用顺序一致。
4. 参考文献条目的题名、作者、来源、年份、卷期、页码、DOI 或 URL 是否能被核验。
5. 正文引用处的论述是否与被引文献题名、摘要、关键词或可访问页面信息明显匹配。

## 三、正文引用抽取

1. 优先识别顺序编码制引用，如 `[1]`、`[1-3]`、`[1,3,5]`、`［1］`。
2. 记录每个引用序号的首次出现位置，包括章节、段落附近文本或页码。
3. 展开连续引用范围，例如 `[1-3]` 应视为引用 1、2、3。
4. 正文出现引用序号但参考文献列表没有对应条目时，列为“引而不列”。
5. 参考文献列表中存在正文未引用条目时，列为“列而不引”。

## 四、参考文献列表解析

1. 识别参考文献区标题，如“参考文献”“References”。
2. 解析每条参考文献的序号、作者、题名、来源、年份、卷期、页码、DOI、URL。
3. Word 中参考文献可能使用自动编号列表。不要仅凭段落文本缺少 `[1]` 或 `1.` 就判定没有编号，应结合 `w:numPr`、`w:ilvl`、`w:numId` 和段落样式判断。
4. PDF 文本提取可能丢失编号。无法确认时列入人工确认，不直接补号。
5. 不因核验到 DOI 就擅自把 DOI 加入论文参考文献列表，除非用户或学校模板明确要求。

## 五、真实性核验优先级

按可用性优先核验：

1. 用户提供的数据库、题录文件、学校图书馆检索结果或参考文献 PDF。
2. DOI 和 `doi.org` 跳转结果。
3. Crossref、出版社官网、期刊官网、会议官网、数据库公开页面。
4. CNKI、万方、维普、国家哲学社会科学文献中心等中文数据库页面；需要登录或校园网时，能访问则核验，不能访问则标注未核验。
5. 可靠网页、机构仓储、作者主页、预印本页面。

检索失败不等于文献不存在。数据库不可访问、检索结果不足或题录信息冲突时，应标为“未检索到”“部分匹配”或“需人工核验”。

## 六、引用正确性判断

判断正文引用语境是否与被引文献基本匹配：

1. 正文引用处的论述主题是否与文献题名、摘要、关键词或页面摘要相符。
2. 文献类型是否支撑正文说法，例如标准、政策、算法、系统框架、调查数据、理论观点。
3. 是否存在把工具文档当作学术研究、把无关论文用于支撑核心结论、或引用过时文献支撑最新事实的问题。
4. 无法获取文献摘要或页面信息时，不做武断判断，应标为“引用正确性需人工核验”。

## 七、核验状态

- 已核验：题名、作者、来源、年份等主要字段与可靠来源匹配。
- 部分匹配：题名或作者可匹配，但卷期、页码、DOI 等字段不完整。
- 疑似错误：检索结果与条目主要信息明显不一致。
- 未检索到：联网检索未找到可靠来源。
- 未核验：当前环境无法联网、用户禁止联网或数据库不可访问。
- 需人工核验：仅凭当前可见信息无法判断真实性或引用正确性。

## 八、修改说明中的核验表

参考文献核验结果写入修改说明，建议使用下表：

| 序号 | 正文首次引用位置 | 原参考文献条目 | 核验状态 | DOI 或可访问地址 | 引用正确性判断 | 处理建议 |
|---:|---|---|---|---|---|---|

如未联网或无法访问数据库，应明确写明未核验原因，例如：

```text
当前环境无法联网或无法访问相关数据库，参考文献真实性核验未完成。以下条目需由作者、指导教师或学校图书馆数据库人工核验。
```

## 九、禁止事项

1. 不得编造 DOI、URL、页码、卷期、期刊名、出版社信息。
2. 不得因检索到 DOI 就擅自把 DOI 加入论文参考文献列表。
3. 不得把检索失败写成“文献不存在”。
4. 不得在未打开或未核验来源时声称“已核验”。
5. 不得用参考文献核验结果替代学术不端调查、查重或教师最终判断。
