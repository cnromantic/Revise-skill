# 单篇修改说明

逐份选模板，先填 Markdown，再将该文件转换为独立 LaTeX 源文件并编译 PDF。单篇使用 `revision-report.md`、`revision-report.tex`，批量汇总使用 `batch-summary.md`、`batch-summary.tex`。四个文件均可单独替换。

对每个模板依次查找：使用者明确指定的文件或模板目录 → 输出目录下的 `revise-templates/` → 技能的 [assets/templates/](../assets/templates/)。仅对缺少的文件使用下一级模板。显式指定的文件读不到或无法编译时，告知具体文件及原因，保留已填内容。始终复制 MD 模板到输出目录另取报告名后填写，保留用户模板原件。

1. 在报告中给出专业、代码或匹配状态、识别依据、论文类型、实际采用的专业检查项与证据位置。
2. 初评、具体修改、修改后复评各自使用独立表格。使用学校量表时替换默认评分行与满分；默认量表覆盖全部二级指标。按项核算初评与复评合计，说明主要问题、已改项与需人工确认项。
3. 具体修改区分已落实的修改、PDF 批注与待落实建议。已修改正文时，第三张表使用“修改后实际复评”，填写实稿分数；只有 PDF 批注时，改用“落实建议后的预计复评”，将默认表中的复评列明确改名为“预计分”。逐项对应原扣分点、批注编号和假设条件；无法估分时按评分量表标为待复评。
4. 参考文献逐项记录原条目、首引位置、核验状态、可核实来源、引用正确性及建议。篇幅较长时按条目编号拆为两个窄表。长地址在 MD 中使用明确的来源名称作链接文字。
5. 按照模板说明摘要与中英文对应、图表或公式、处理方法、跳过文件和待复核事项，删除填写提示。自定义模板亦须保留三张核心表及以下文末原文；以本条补足缺少的部分。

说明：本修改说明由人工智能辅助生成，仅供论文修改与评审参考，最终结论请以指导教师、评阅教师及学校相关管理部门审核意见为准。
