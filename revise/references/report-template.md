# 修改说明模板

`论文题目-修改说明.md` 使用以下结构，并尽量将同一内容转换为 `论文题目-修改说明.pdf`。

## PDF 排版要求

修改说明 PDF 应使用真实表格，不得把 Markdown 表格原样作为纯文本写入 PDF。

建议排版参数：

- 页面：A4；
- 页边距：18-22 mm；
- 中文字体：Microsoft YaHei、SimSun、SimHei 或其他可用中文字体；
- 标题：16-18 pt；
- 一级小标题：12-14 pt；
- 正文：不小于 10 pt，建议 10.5 pt；
- 表格文字：不小于 9 pt，建议 9.5-10 pt；
- 表格线：0.5 pt 灰色或黑色实线；
- 表头：浅灰或浅黄色底色；
- 单元格：自动换行，顶部对齐，内边距 4-6 pt；
- 多页表格：重复表头；
- 宽表：拆分为多个窄表，或改用横向页面，不能把字体压得过小。

初评表、具体修改表、复评表必须有清晰网格线。若工具链无法直接生成友好 PDF，应生成 HTML 或 DOCX 中间稿后转 PDF。
