# Word 论文处理规则

处理 `.docx` 或 `.doc` 输入时：

1. 保留原文件，不覆盖。
2. 读取段落、标题、表格、图表题、页眉页脚等可读结构。
3. 生成新的 `论文题目-修改稿.docx`。
4. 对修改处或问题处使用黄色突出显示。
5. 尽量保留图片、表格和原版式。
6. 自动处理无法保留复杂格式时，必须在修改说明中列明。
7. 除非环境可靠支持，不主动更新 Word 自动目录；必要时提示用户在 Word 中更新域。
8. 黄色突出显示必须尽量保留原 run 的字符级格式。若修改文字包含或紧邻参考文献引用序号、脚注尾注标记、上下标、域代码或超链接，不得整段清空后重建为单一 run；应采用 run 级局部替换、局部高亮，或将高亮范围避开这些特殊格式。
9. 对正文参考文献引用，原为上标的编号必须继续保持上标。若工具无法可靠保留引用上标，应只修改引用前后的普通文字，或在修改说明中给出建议，不直接改写该段。

只直接修改低风险问题。缺少证据、截图、测试数据和不可核验参考文献时，不编造内容，应写入批注或修改说明。
