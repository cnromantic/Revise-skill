# Word 论文处理规则

处理 `.docx` 或 `.doc` 输入时，必须以保留原始版式和可追溯修改为目标。

## 一、文件优先级

1. 同一目录中如果存在同主名 Word 与 PDF，例如 `论文题目.docx` 和 `论文题目.pdf`，默认只处理 Word。
2. 跳过同名 PDF 时，在修改说明、批量汇总或处理日志中写明：`已发现同篇 Word 文档，默认以 Word 为准，PDF 未处理。`
3. 同篇判定优先按文件主名完全一致。若文件名包含“终稿、最终版、修改版、定稿、查重版、打印版”等后缀，不做复杂合并，除非用户明确指定。
4. 无法确定是否同篇时，不自动跳过，应列入人工确认或按用户指定处理。

## 二、复制后处理

1. 保留原文件，不覆盖源文件。
2. 先复制源 Word 为 `论文题目-修改稿.docx`，再在副本上处理。推荐流程：

   ```python
   shutil.copy2(source_docx, revised_docx)
   ```

3. 只在副本上做局部修改，不得从纯文本重新生成整个 Word。
4. 对 `.doc` 文件，应优先转换或复制为可处理的 `.docx` 副本；无法可靠转换时，在修改说明中列明限制，不得声称已完成 Word 正文修改。
5. 修改完成后检查修改稿文件存在、源文件未被覆盖、图片和表格未明显丢失。

## 三、读取与修改范围

读取段落、标题、表格、图表题、页眉页脚、脚注尾注、目录、参考文献列表等可读结构。只直接修改低风险问题：

- 明显错别字、标点、病句；
- 题目和正文能明确支撑的摘要表述；
- 明确的图表编号、标题层级和术语一致性问题；
- 明显模板残留且替换对象唯一明确的问题。

缺少证据、截图、测试数据和不可核验参考文献时，不编造内容，应写入批注或修改说明。

## 四、局部替换与黄色高亮

1. 优先进行 run 级局部替换，尽量保留原样式、上标、超链接、脚注、域代码和字符格式。
2. 黄色高亮只标记实际修改文字或问题短语，不要整段变黄。
3. 含公式、图片、复杂表格、脚注、尾注、参考文献上标的段落，能不整段重建就不整段重建。
4. 若修改文字包含或紧邻参考文献引用序号、脚注尾注标记、上下标、域代码或超链接，不得整段清空后重建为单一 run；应采用 run 级局部替换、局部高亮，或将高亮范围避开这些特殊格式。
5. 对正文参考文献引用，原为上标的编号必须继续保持上标。若工具无法可靠保留引用上标，应只修改引用前后的普通文字，或在修改说明中给出建议，不直接改写该段。
6. 自动处理无法保留复杂格式时，必须在修改说明中列明。

## 五、自动编号与多级列表

Word 自动编号不一定出现在 `paragraph.text` 中，不能仅凭提取文本没有 `1`、`1.1`、`[1]` 就判定缺号。

处理标题、目录和参考文献编号时：

1. 检查段落 OOXML 编号属性，如 `w:numPr`、`w:ilvl`、`w:numId`。
2. 结合段落样式判断，如 `标题 1`、`标题 2`、`Heading 1`、`Heading 2`、`List Paragraph` 等。
3. 参考文献区如果使用自动编号列表，不得再手动插入 `[1]` 或 `1.`。
4. 如果学校模板要求参考文献显示为 `[1]`，但 Word 采用自动编号，应在修改说明中提示“建议人工确认参考文献编号显示样式”，不要直接把自动编号段落重建为手工编号段落。
5. 标题编号如由 Word 自动多级列表生成，应视为已有编号；只检查层级连续性、目录与正文一致性，不要直接补号。
6. 除非环境可靠支持，不主动更新 Word 自动目录；必要时提示用户在 Word 中更新域。

## 六、验收要求

完成 Word 处理后检查：

1. 源 Word 文件未被覆盖。
2. `论文题目-修改稿.docx` 已生成。
3. 修改处或问题处有黄色高亮。
4. 原图片、表格、脚注、页眉页脚、引用上标未明显丢失。
5. 参考文献或标题自动编号未被重复添加。
6. 修改说明列明处理方式、未能直接修改的问题和需人工确认项。
