# 多篇汇总填写规则

采用 [单篇说明中的模板优先级与文末原文](report-template.md)，逐文件选择 `batch-summary.md`、`batch-summary.tex`。逐篇完成的修改说明是汇总的数据来源。输出名称为 `X篇论文处理汇总`，分别保留 .md、.tex 和 .pdf。

- 开头列发现文件数、实际处理篇数、跳过同篇 PDF 数、成功生成修改稿和完整说明数、需人工确认篇数。X 按实际处理的不同论文计数。待确认专业、读取失败、编译失败分别登记，不把未完成项标为成功。
- 初评结果表逐篇列专业、类型、分值和依据；具体修改表逐篇列位置、修改或批注、状态与输出完整性；修改后复评表记录分数变化及证据。逐篇沿用单篇的实际／预计口径与前提；尚不能估分的填“待复评”，实际与预计分分别标识，不混算。
- 同篇文件跳过原因与对应处理对象、共性和差异、各篇参考文献核验状态、未核验条数、人工复核清单与优先级均应可追溯到单篇记录。
- 使用论文代号或脱敏题名，避免在汇总中暴露姓名、学号、签名、联系方式和个人路径。三种格式逐项核对计数、分数和文末说明。
