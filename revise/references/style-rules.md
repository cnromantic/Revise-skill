# 语言、标点与中英文混排规则

## 中英文空格

默认原则：中文说明性文字中，不机械地在英文术语前后增加空格；英文固定短语内部原本的空格应保留。

推荐写法：

- 系统采用Spring Boot框架实现业务逻辑。
- 前端采用Vue.js构建响应式界面。
- 基于RBAC的权限控制。
- 通过RESTful API实现数据交互。
- 使用MySQL数据库。

以下场景保留必要空格：

- English abstracts and English sentences;
- code, commands, config, API paths, URLs, file paths;
- mathematical expressions and variables;
- fixed English phrases such as Spring Boot, Visual Studio Code, RESTful API;
- units such as 16 GB RAM;
- database fields such as user_id and course_id;
- reference titles, journal names, and publisher names.

## 常见术语规范

- 正文中写 Spring Boot，不写 SpringBoot；引用文献题名时可保留原题名。
- Vue.js 或 Vue 3，全文保持一致。
- MySQL, RESTful API, JWT, RBAC, E-R图, UML, PDF, Word.
- 前端/后端 for architecture; 前台/后台 only when referring to user-facing/admin-facing systems.
- 黏性 for "用户黏性".
- Key words or Keywords; keep one style consistently.

## 保守修改

修改明显错别字、语法错误、标点错误和口语化表达。不要过度润色成无依据结论，也不要改变学生论文的核心研究内容。
