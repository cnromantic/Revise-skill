# 从专业和论文类型确定评审重点

每篇先读封面（包括表格、文本框、图片中的专业栏）、题目及中英文摘要。用专业全称或代码检索 [本科专业目录](undergraduate-major-catalogue.md)，再核对其上级专业类、门类和原注。院系、学位门类、研究方向、软件名称和论文类型均不能单独充当专业。目录跨页注记、T/K 后缀和历史代码应保留。

- 封面专业清楚且与目录相符，按该专业登记；题目跨学科时另记研究方法与领域。例如教育学专业研究在线学习平台的教学效果，评审重点是教学干预及效果证据。
- 封面缺项时，可由题目和摘要中明确、相互印证的信息识别专业并注明依据。如果只能判断专业类、候选专业不唯一、专业栏冲突或扫描件难辨，先问使用者“这篇论文所属的本科专业全称是什么？”批量时列出待确认的论文，继续处理专业已明的其他篇目。
- 校内专业名、旧称、方向班按用户确认的原称记录。仅在目录关系明确时列代码；目录无对应项就注明“目录未匹配”。确认后再进行专业评价和打分。

## 按实际研究方法选择证据

先记录“专业及依据、论文类型、两至四个专项问题、各自证据位置”。以下是取证示例。根据具体题目把每项改写为可在正文或附件回答的问题。批量任务逐篇决定；同一专业的理论、实证、设计和创作论文可以使用不同的证据。

| 门类与示例 | 阅读时核对什么 | 评语落点 |
|---|---|---|
| 01 哲学 | 标出核心命题、原典出处、概念界定与反例 | 论证的哪一步需要额外前提？不同译本的术语是否一致？ |
| 02 经济学 | 理论假设、变量口径、数据年份、样本与识别策略 | 实证结论能否支持因果措辞？理论论文核对假设到结论的推导。 |
| 03 法学 | 法学核对规范层级、适用时点、案例事实与论证；社会学核对访谈取样、编码与反例 | 条款能否支撑该解释？质性研究结论是否超出样本范围？ |
| 04 教育学 | 教育对象、课程目标、干预与测量；体育学核对训练负荷、指标和观察周期 | 测量是否对应目标？区分教学设计、实际实施和学习效果。 |
| 05 文学 | 文本版本、引文页码、细读与解释；翻译核对原译对照、策略和语境；新闻传播核对语料抽样 | 所举原文或传播材料如何支撑具体判断？ |
| 06 历史学 | 史料出处、年代、形成背景和互证关系 | 区分一手史料、后人转述与作者推断，核对时间线。 |
| 07 理学 | 数学核对定义域、定理条件、证明和公式引用；实验类核对测量单位、对照、误差和不确定性 | 精确指出缺失的条件或测量证据，核心证明与实验结果交作者确认。 |
| 08 工学 | 根据设计对象检查约束、计算或图纸、验证方法和需求对应；软件开发型另读软件专项清单 | 建筑设计核对空间与尺度，机械设计核对载荷与选型；按论文交付物评价验证。 |
| 09 农学 | 品种与环境、处理组和重复、指标口径、观察时间 | 单季或单点结果推广到其他环境的依据是什么？ |
| 10 医学 | 研究设计、纳排标准、样本流向、伦理与隐私说明、结局指标；综述核对检索与筛选 | 区分研究观察与临床建议；未见伦理或原始材料时交人工核验。 |
| 12 管理学 | 管理问题、组织情境、调查工具、指标与对策的对应；会计核对期间和财务口径 | 哪条访谈、报表或案例证据支撑某项管理建议？ |
| 13 艺术学 | 创作意图、参照作品、草图与迭代、成品与展示记录；艺术史论核对作品和图像出处 | 说明形式选择如何服务主题；区分设计设想与已展示成果。 |
| 14 交叉学科 | 分别列出各领域提供的方法、输入输出及交叉环节的验证证据 | 核对数据尺度、术语与方法边界，判断结论能否由组合证据支持。 |

将专项发现放入通用评分表的“逻辑结构”“综合应用知识能力”“分析解决问题能力”等相应行，沿用原权重。同一证据在初评和复评使用同一口径。只对有依据的低风险表述和格式作局部修订。缺失的原始记录、证明、访谈、伦理审批、史料和创作过程列入人工确认。
