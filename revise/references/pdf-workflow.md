# PDF 论文处理规则

处理 `.pdf` 输入时：

1. 判断页数、是否加密、是否扫描件、是否有可提取文本层，以及当前环境可用的 PDF 工具。
2. 能提取文本时，先提取正文、目录、图表题、参考文献和页码位置。
3. 文本提取失败且用户没有要求 OCR 时，不强行全文 OCR。
4. 若工具支持可靠的 PDF 原位文字替换和高亮，可生成直接修改后的 PDF。
5. 若无法可靠替换正文，应生成“就近批注式修改稿”。

PDF 只输出 3 个文件：

```text
论文题目-修改稿.pdf
论文题目-修改说明.md
论文题目-修改说明.pdf
```

## 就近批注式修改稿

就近批注式修改稿应尽量接近人工 PDF 批注效果：

1. 在问题文字下方或右侧附近添加黄色批注框；
2. 批注框离问题位置不要太远；
3. 批注框可以遮住附近不需要修改的文字，但不得遮住需要修改的问题文字；
4. 批注框使用黄色背景和清晰边框；
5. 批注内容要短，说明问题和建议改法；
6. 支持箭头或短线时，用箭头或短线指向问题文字；
7. 对无法定位到精确坐标的问题，在对应页添加页面级批注，并在修改说明中写明限制；
8. 如果只是批注而未替换正文，不得写成“已完成正文替换”。

所有逐项建议和可替换文本都合并写入修改说明，不再单独输出额外 Markdown 文件。
